🎯 Regras do Jogo

  • Cada jogador possui duas grelhas 10x10.
  • Os navios são posicionados na horizontal ou vertical.
  • Os navios não podem tocar entre si.
  • Em cada turno, o jogador dispara 3 tiros.
  • O adversário informa: se acertou, tipo de navio atingido, ou se foi água.
  • Ganha quem afundar todos os navios primeiro.
